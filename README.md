# Excel実践ポートフォリオ

# 【概要】
Excelを用いたデータ入力、データ整形、データ集計練習の成果物です

## 【学習内容】
以下の関数及びピポットテーブル、条件付き書式を使用し、データ入力およびデータ整形、データ集計を実施

「関数一覧」
- IF
- VLOOKUP / XLOOKUP
- SUMIF / COUNTIF
- LEFT / MID / RIGHT / LEN
- FIND
- ISERROR
- TRIM / SUBSTITUTE

「条件付き書式を活用したこと」
- 重複削除
## 【成果物一覧】

### １．通販会社の顧客名簿の整形 ※１
- 氏名を整形
- 電話番号を整形
- 郵便番号を整形
- 会員区分に応じた会員ランクを追加
- 特定の会員区分の合計購入金額を算出
- 特定の会員ランクに応じた人数を算出

### ２．ECサイト運営会社での売上データの整形 ※１
- XLOOKUP / VLOOKUPによる商品照合
- 売上金額算出
- 高額商品判定を追加
- 商品別・日付別売上合計および高額商品の件数をピポット分析

### ３．他部署から送られてきた崩れたCSVデータの整形 ※１
- 顧客名の重複削除及び整形
- メールアドレスを整形
- 都道府県を整形
- 売上を通貨形式から数値形式に変換
- 都道府県別の売上合計・売上平均および顧客名ごとの顧客数をピポット分析

※１・・・成果物3点についてデータ整形した手順および実施したことは各成果物ファイルの「整形後」シートに記載
